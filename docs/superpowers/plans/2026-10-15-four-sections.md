# 四板块本地工具实施计划

目标：界面仅保留企业信息、招聘信息、面试记录、简历修改，不依赖大模型。保留黑白、粗宋体、大字号与红砖图标。

1. 企业数据：扩展 core 的类型、校验、文件存储和 HTTP 记录接口；测试持久化、更新冲突、删除和导出。
2. 页面：增加企业 CRUD；招聘使用企业名称候选；移除笔记、个人资料、模型设置、AI 问答和简历建议；面试使用手动记录与完成/重新打开。
3. 回归：浏览器覆盖四板块、刷新持久化、简历版本、面试修改、无 AI 请求和窄屏布局。运行类型检查、单元测试、构建与 E2E。
4. 更新 README；重启本地持续运行的服务，验证实际页面。

旧笔记和历史模型数据保留在本地文件中，不执行数据删除。CLI 旧接口兼容。
